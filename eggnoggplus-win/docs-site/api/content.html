Content registry

An all-or-nothing registry for owner-qualified symbolic tiles. It provides strict data identity and rendering/collision composition; richer per-map behavior belongs in the restricted map Lua API.

Complete registration

mod.assets.load_spritesheet("terrain", "assets/terrain.png", {
  cell_w=16, cell_h=16, padding=0
})

local tx, err = mod.content.begin()
assert(tx, err)

assert(tx:register_tile({
  id="moss_floor",
  name="Moss Floor",
  sheet="terrain",
  sprite_index=0,
  frame_count=4,
  frame_ticks=6,
  animation="loop",
  collision="solid",
  native_visual="underlay"
}))

assert(tx:commit())

A commit replaces the owner's entire prior set. Commit an empty transaction to remove it. Validation/allocation failure preserves the previously committed registry.

Tile definition fields

FieldType and contract
idRequired local id. Letters, numbers, period, underscore, and hyphen; at most 47 characters; cannot begin with period/hyphen.
nameOptional bounded display/debug name.
sheet / sprite_sheetRequired mod-owned sheet id or builtin:sprites, builtin:tiles, builtin:misc, or builtin:glyphs.
sprite_indexZero-based cell inside the resolved sheet.
frame_count, frame_ticksDeterministic contiguous animation range and ticks per frame.
animationloop, ping_pong/pingpong, or once.
layerNative sprite batch 0 or 1.
collisionnative, solid, pass_through, or hazard.
native_glyphVerified safe native behavior glyph used when collision is native.
force_modeadd or set.
force_x, force_yPer-tick axis change in -64..64; presence opts the axis in.
max_speed_x, max_speed_yAbsolute axis clamp used with a declared force.
native_visualreplace or underlay. Underlay renders native terrain beneath the custom sprite.
mirror_with_room, random_phaseBoolean mirrored presentation/force and deterministic per-cell animation phase.
offset_x/y, scale, scale_x/y, angle/angle_degreesFinite bounded presentation transform.
tintExactly four normalized RGBA numbers.
asset_sha256Optional exact pin for a mod-owned sheet. The framework hashes the actual registered bytes.
Unknown keys, fractional integer fields, unsafe glyphs, invalid enums, non-finite values, malformed tint, out-of-range sprites, and duplicate ids are errors. They are not coerced.

Collision and behavior boundary

Collision presets map to verified native behavior: solid uses ordinary ground, pass-through uses platform behavior, and hazard uses native lethal terrain. Declarative forces are intentionally small deterministic shortcuts. Use map.lua for contact filters, one-shot springs, sprite response, velocity limits, and state.

The registry does not create arbitrary entities, weapons, combat hitboxes, or moving physics bodies. A native K glyph remains a separately spawned fixed native hazard and is not the custom-entity API.
