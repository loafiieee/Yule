Framework API

A source-backed reference for every public ordinary-mod function, property, compatibility alias, content transaction method, and deterministic map-script callable.

Choose an API area

Runtime & lifecyclePackage metadata, callbacks, configuration, storage, interop, input, and process-exit behavior. UI & renderingImmediate drawing, widgets, custom states, native controls, spritesheets, fonts, textures, and animation. Gameplay & onlineTelemetry, deterministic state, input simulation, bots, map selection, presentation, and online suspension. AudioSound effects, music, bounded generated bytebeat, ownership, cache, and mixer diagnostics. Content registryTransactional symbolic tiles, strict definitions, lookup, identity, and current runtime boundary. Files & networkingUser-mediated file selection, bounded TCP slots, and asynchronous WinHTTP requests. Map LuaRestricted deterministic callbacks, sensors, contact objects, tile presentation, state, and private RNG.

Shared conventions

ConventionMeaning
[argument]Optional positional argument. The function entry documents its default.
true / false, errorRecoverable framework operation. Always inspect the second result when false.
Lua errorProgrammer/contract violation. The owning callback or mod load is stopped and a categorized diagnostic is written.
gameplayRegisters or changes gameplay behavior and is suspended/refused during managed online play.
read-onlyObserves current framework/native state without requesting mutation.
legacyRetained for compatibility but not recommended for new packages.
Installed ordinary mods are trusted code. Their global tables are isolated, but they share one Lua VM and may use the standard Lua libraries, local dialogs, TCP, and HTTP surfaces described here.

Minimal package context

-- mods/example/main.lua
mod.on_load(function()
  mod.log(("%s v%s, framework API %d"):format(
    mod.name, mod.version, mod.framework_api))
end)

mod.on_frame(function()
  mod.ui.begin_overlay()
  mod.ui.text_at("Example mod", 12, 12)
  mod.ui.end_overlay()
end)
