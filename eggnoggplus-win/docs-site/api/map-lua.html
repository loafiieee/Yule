Deterministic map.lua

A V2 package may place one map.lua beside data.json and data.map. The restricted VM adds bounded tile contact behavior without filesystem, network, OS, UI, audio, dynamic code, modules, FFI, debug, or process access.

Execution model

  • The loader discovers one direct non-reparse map.lua; JSON does not name it.
  • The retained source and canonical tile bindings are part of map identity and online compatibility.
  • Callbacks cannot capture upvalues. Persist simulation values in map.state.
  • Contact order is deterministic: top-to-bottom, left-to-right map order over one immutable pre-callback physics sample.
  • A callback fault restores its partial object/tile/state changes, disables script behavior, and leaves native collision/render fallback active.
  • Script state, private RNG, tick clock, contacts, velocity limits, and sprite overrides participate in rollback.

Sensor options

OptionContract
tile_box{left,top,right,bottom} in tile-local coordinates. Quantized to 1/256 cell; edges -2..3; positive size. Default full cell.
object_boxcenter, body, feet, or relative edge table in -2..2. Body uses the verified native contact radius.
objectsDense non-empty list from player, alive_player, dead_body, sword, and opt-in hazard. Legacy player includes living and dead records.
contact_scopecell or binding. Binding unions touching cells of the same definition to avoid seam re-entry and multiplied callbacks.
mirror_with_roomMirrors the tile box horizontally on the mirrored side.

Filter intentionally. Repeatedly launching a corpse can prevent the native grounded-respawn gate. Different gravity also means one velocity does not create the same arc for players, swords, and hazards.

Complete spring and fan

map.sensor(">", {
  tile_box={left=0, top=0, right=1, bottom=.375},
  object_box={left=-.375, top=0, right=.375, bottom=.375},
  objects={"alive_player", "sword"},
  contact_scope="binding"
})

map.on_enter(">", function(object, tile)
  local launch = object.kind == "player" and -4.0 or -2.8
  object:set_velocity(object.vx, launch)
  object:set_velocity_limits({min_vy=launch}, 8)
  tile:set_sprite(129, 16, {offset_y=8})
  map.state.spring_hits = (map.state.spring_hits or 0) + 1
end)

map.sensor("}", {
  object_box="body",
  objects={"alive_player", "sword"},
  contact_scope="binding",
  mirror_with_room=true
})

map.on_contact("}", function(object, tile)
  local push = tile.mirrored and -0.25 or 0.25
  object:add_velocity(push, 0)
end)
