Files & networking

Owner-bound Unicode file selection, strict JSON conversion, bounded recursive lookup, nonblocking TCP streams, and asynchronous WinHTTP GET requests.

File picker: use mod.fs.pick_file(options) for new work. Its filters are explicit and bounded; the character-specific helper remains only for API-v1 compatibility.
Trusted-mod boundary: these APIs can show native dialogs and contact external systems. Validate all remote data, bound your own buffers, close slots, and never place credentials in logs.
