Getting started

First launch

Use this two-minute check to confirm that the proxy, Lua runtime, menus, and logs are all working before adding your own content.

1. Start the game normally

Run eggnoggplus.exe from the installed folder, a shortcut made by the installer, or its Steam entry. Do not start YuleUpdater.exe. The game should reach a menu without a Windows missing-DLL dialog.

The first start may create the mods/ log and settings files and begin a background update check. Network failure during that check should not stop the menu.

2. Open framework settings

Open Options → Mods. The list contains the framework section and every discovered mod with a valid manifest. The framework section is where you can inspect its version, update status, log-console visibility, and Discord Rich Presence setting.

The separate log window is optional. Release installs default it to hidden. This does not disable file logging or the in-game developer console.

3. Check the developer console

Press backtick (`) to open the in-game console and enter:

framework.api
mods.list
state
log.tail 20

You should see an API version, discovered mods, the current state name, and recent log lines. Press Esc or backtick again to close it. If your keyboard layout does not expose backtick conveniently, the complete console guide still applies once the console is opened.

4. Check the file log

Open mods/modframework.log in a text editor. Errors are labeled with [ERROR] and a subsystem or mod ID. A mod failing to load does not necessarily mean the entire framework failed.

Useful neighboring files include:

  • mods/crash.log — framework crash records when the handler can write one.
  • mods/desync_dump.log — rollback diagnostics generated after an online mismatch.
  • mods/console_history.txt — persisted developer-console commands.
  • mods/updater.log — bounded updater/recovery status.

Safe first choices

  • Leave developer mode off. Commands hidden behind dev on can intentionally alter state.
  • Try bundled demonstration mods offline before changing their files.
  • Use the Mods menu to disable unwanted mods instead of deleting folders while the game runs.
  • Before online play, keep both players on the same framework/content versions.

Original game controls

The framework does not replace Eggnogg+’s normal controls. Defaults are WASD plus Left Control/Shift for player one and arrow keys plus Period/Comma for player two. The gear menu can remap controls. F1 cycles window sizes, F11 toggles fullscreen, and F5 restarts an ordinary offline game. Function keys are guarded differently during online matches.
