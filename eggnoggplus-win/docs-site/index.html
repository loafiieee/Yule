Know the boundary

Ordinary mods are trusted. They share one Lua VM and can use standard Lua libraries, local dialogs, TCP, and HTTP. Install only reviewed packages.
Gameplay mods stop online. Tick handlers, content registration, bots, and gameplay mutation are classified and suspended while managed rollback owns the match.
Map scripts are different. A V2 map.lua runs in a separate restricted deterministic VM with bounded memory, instructions, state, callbacks, and no filesystem/network/process access.
