Developer console

Press backtick (`) to open Yule's in-game console. It provides day-to-day framework administration, diagnostics, live mod configuration, and an explicitly gated set of invasive developer tools.

Do not paste secrets into commands. Command history persists in mods/console_history.txt. The authenticated direct-netplay key path deliberately reads a one-use key from the clipboard and clears it.

Input and history

ControlBehavior
EnterRun the current command.
Up / DownBrowse persisted command history.
Left / Right, Home / EndMove through the input line.
Backspace / DeleteEdit at the cursor.
TabComplete command names and supported arguments: mod ids, config/bind keys and values, states, and log levels. Multiple matches are listed and extended to their common prefix.
PageUp / PageDown or wheelScroll output.
Ctrl+LClear visible output.
Ctrl+CCopy input; with empty input, copy console output.
Ctrl+V or right clickPaste into input.
Middle clickCopy console output.
Esc, exit, quitClose the console; these do not exit the game.

Online hub and connectivity

CommandPurpose
online.hubLoad and open the online hub. online is accepted as an alias although it is omitted from autocomplete.
online.troubleshoot, net.troubleAsynchronously test TCP control and UDP rendezvous against the configured server and print Windows route, adapter, NAT/CGNAT, firewall, and VPN evidence. VPN conclusions are heuristic.
net.diagPrint a secret-free snapshot of server state, active match, selected route, attempts, and packet counters.

The troubleshooter does not pause gameplay. Run it before queueing, and run net.diag while a connection is actually stuck. An unrelated active virtual adapter is evidence, not proof that traffic is routed through it; the named server-route adapter is the important result.

Rollback netcode commands

Developer gate: all ggpo.* commands require dev on. Hub matchmaking normally supplies authenticated endpoints and settings automatically; these commands are for controlled tests.
CommandContract
ggpo.net, ggpo.net statusPrint connection, frame/ack/checksum, packet, correction, simulation, socket, and build-fingerprint diagnostics.
ggpo.net offStop the current direct debug session. Aliases: stop, disable.
ggpo.net keyRead exactly 64 hexadecimal characters from the clipboard, clear the clipboard, and arm the key for one successful v17 host/join. The key is not typed, persisted, or logged.
ggpo.net key clearDiscard an armed one-use key. off is also accepted after key.
ggpo.net host [port]Host an authenticated UDP rollback session as player 0.
ggpo.net join <host> [port] [local_port]Join as player 1, optionally binding a chosen local UDP port.
ggpo.net hud [on|off]Inspect or persist the default-off small active-match ping/input-delay/rollback overlay. Alias: overlay.
ggpo.net delay [0..8]Inspect or set local input delay. Alias: input_delay.
ggpo.net autodelay [on|off]Toggle RTT-derived automatic input delay. Alias: auto_delay.
ggpo.net advantage [0..220]Inspect or set frame-advantage throttling. Aliases: max_advantage, timesync.
ggpo.net predict [1..220]Inspect or set maximum prediction before stalling. Aliases: prediction, max_prediction.
ggpo.net highping [1..220]Apply a conservative latency budget that favors bounded pauses over long prediction. Aliases: latency, budget.
ggpo.net smoothping [1..220]Apply an aggressive profile favoring smoothness at greater correction risk. Aliases: smooth, aggressive.
ggpo.net correction [on|off|status]Control host-authoritative correction after detected divergence. Aliases: correct, resync.
ggpo.net sim [loss 0..100] [min 0..120] [max 0..120]Simulate outgoing UDP loss and delay in ticks. sim off, clear, or none removes it. Alias: netem.
ggpo.net rngtrace [on|off]Log live frames that consume gameplay RNG; use only for a short desync capture.
ggpo.roundtripNon-invasive save/load/checksum callback test.
ggpo.selftest [frames]Invasive hidden-frame replay test; do not use during another rollback session.
ggpo.local [toggle|on|off|status]Route local gameplay through the GGPO-shaped save/load/advance callback session.

Only one loopback, local, self-test, or network harness can own rollback at a time. There is no working ggpo.loopback console dispatch in the current source; use F3 for the live loopback harness.

Developer mode and power tools

dev on
# run diagnostic commands
dev off

Developer mode controls command visibility, autocomplete, and dispatch. It gates ggpo.net, ggpo.roundtrip, ggpo.selftest, ggpo.local, state.switch, input.*, arbitrary Lua, and log.tail.

CommandPurpose
lua <code>, eval <code>Execute code in the framework console Lua environment and print returned values.
lua.mod <id> <code>, eval.modExecute inside a loaded mod's environment.
lua.file <path>Execute a Lua file. Treat it exactly like installed trusted code.
log.tail [lines]Print recent framework log lines in-game.
input.show [player]Inspect active input override state.
input.override <player> <mask> [frames] [replace]Inject decimal or 0x input mask; negative frames persist until cleared. replace controls replacement versus merge.
input.clear <player>Remove an injected override.
Arbitrary Lua and forced state/input commands can crash or corrupt the current session. They are test tools, not stable automation interfaces.

Useful command sequences

Inspect and change a mod setting

mods.find speed
mods.info speedhack
mods.config speedhack
mods.config.set speedhack max_speed 3.5

Diagnose an online failure

online.troubleshoot
net.diag
dev on
ggpo.net status
ggpo.net rngtrace on

Authenticated direct two-client test

# Copy the same random 64-hex value on each client:
dev on
ggpo.net key
# Client A:
ggpo.net host 47777
# Client B, after independently arming the same key:
ggpo.net join 203.0.113.10 47777

Test generated audio from a loaded mod

dev on
lua.mod options_demo return mod.audio.play_bytebeat(
  "t*((t>>12|t>>8)&63&t>>4)",
  {duration=4, loops=1, volume=.6}
)
