# Object designer

Object authoring is part of the current Greggnogg map. Open **Objects** in the
command bar, edit appearance and logic, and choose **Done**. Select the resulting
design under **Custom tiles** and place it using the regular map tools.

The old standalone page redirects to Greggnogg. `core.js` contains shared
package validation and atlas helpers; it is not a separate project workflow.

See [the editor guide](../README.md#entity-content-authoring) for export and
runtime limitations.
